INITIAL QUESTION

The telescope view initially appeared inconsistent with the public A8
Moons animation.

An observed moon was first identified as Callisto and appeared too close
to Jupiter.

The identification was corrected:

the moon in question was Io.

FOLLOW-UP RESULT

Comparison of the observation against the underlying Jovian model found
no reason to reject or retune the A8 moon-position model.

The apparent discrepancy came from the public cartoon / rail rendering,
whose displayed proportions are useful for quick visual reference but
are not intended to reproduce telescope-image scale with astronomical
precision.

PUBLIC DISPLAY ROLE

The A8 Moons display is a reference and heads-up instrument.

It is not intended to be:

a precision planetarium
an astrometric reduction tool
a telescope-image simulator
an authoritative external ephemeris

Its purpose is to make the native Jovian recurrence and approximate
relative configuration easy to see.

The underlying model and the cartoon presentation must therefore remain
conceptually separate.

MODEL
native recurrence / phase / coordinates

DISPLAY
human-readable visual approximation

OBSERVATION POLICY

Public comparison and criticism are welcome.

An apparent visual mismatch is useful evidence and should trigger a
comparison against the underlying coordinates before either the observer
or the model is declared wrong.

The Sep-15 observation is a good example:

visual cartoon mismatch
→ telescope inspection
→ moon identification corrected
→ underlying model checked
→ display-proportion limitation identified
→ no model retune
