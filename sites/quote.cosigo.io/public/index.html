why pool curves matter

A pool quote is not a flat shelf price. The first CIGO in a trade may clear near the visible pool price, but each additional unit changes the reserves. That means a larger buy or sell walks along a curve and receives an average price, not one fixed price for the whole order.

plain example

A small trade may look close to the reference price. A large trade can look very different because it consumes a meaningful part of the active CIGO / BSC-USD pool. The request desk uses the live router estimate first, then applies a small manual desk premium, instead of pretending every CIGO clears at the same flat reference price.

wallet price visibility

Wallet apps may display zero or stale values when third-party data providers have not recognized a market price. The live request quote above is more useful because it is tied to the active pool route used for CIGO / BSC-USD.
