INVESTIGATE · why dragging cannot contaminate A8 timing

The horizontal bar contains exactly 64 native slots. Each slot is exactly 1/16 A8 second.

Dragging only changes the ordering of explicit NOTE and REST events. The score engine immediately recomputes every START and END from exact native slot arithmetic.

Mouse coordinates, pixels, animation frames, packet arrival and browser elapsed time never become score timing.
