2 · STOPPED-CLOCK WALKABOUT — ORION / DECIMAL COMFORT

DUMMY PERSPECTIVE / NORTH-TO-SOUTH TRAVERSE

The ordinary east-west daily rotation is removed. Night is all around. The observer walks the meridian great circle while the whole visible sky changes orientation with the observer’s local vertical.

A8 latitude pendulum:
North Pole 0 → Equator 128 → South Pole 256 → Equator 128 → North Pole 0.

The opposite side is carried by longitude, not by inventing a second set of latitudes.
Observer insight:
this isolates why constellations look upside down, sideways, or unfamiliar across hemispheres. The stars are fixed. The observer’s local frame rotates as travel proceeds across the spherical Earth.
WHAT YOU’RE SEEING
This is a frozen-sky, frozen-Earth experiment. The stars are fixed and the Earth is not rotating. The only motion is the dummy observer walking around the curved surface of the Earth. As the observer changes position, the local horizon changes with the curvature of the Earth, so some stars move below that horizon. Those hidden stars turn grey so the underlying geometry remains visible.

STARS: FIXED · EARTH: FROZEN · OBSERVER: WALKING · GREY = BELOW LOCAL HORIZON

Scorpius lies well into the southern celestial sky, so from northern latitudes it naturally stays below the local horizon for more of this stopped-clock route. Earth’s ordinary daily spin would make stars rise and set with time, but it does not erase this north/south geometry.

LAB NOTES / FAQ

SHORT ANSWERS UP FRONT
Why is Polaris “over there” on the flat map?
Because the map is distorted near the pole. Polaris is very close to the pole, but not exactly on it, so it keeps a real coordinate while the rectangular sheet stretches the entire polar zone.
Why does Orion look upside down in the Southern Hemisphere?
Because the observer moved around a spherical Earth. The constellation did not flip in space; the observer’s local “up” rotated with location.
Why no +90 / 0 / −90 latitude here?
Because A8 uses a physical pole-to-pole ruler: North 0, Equator 128, South 256. Returning around the same meridian great circle naturally gives 128 and 0 again.

AUSPICIOUS 8 · RULER SYMMETRY

WHY 131,072? · CLOCK ↔ EARTH ↔ SKY

A8 uses distinct rulers to describe the same physical Earth rotation. The physical motion does not change. One ruler expresses its elapsed time; the other expresses its angular displacement. Because one complete Earth day and one complete turn are two descriptions of the same recurrence, both rulers use 131,072 = 2^17 terminal graduations.

A8 TIME · ONE EARTH DAY

32 × 64 × 64
= 131,072
= 2^17
HOUR · MINUTE · SECOND

A8 ANGLE · ONE FULL TURN

512 × 16 × 16
= 131,072
= 2^17
ANGLE · ARC MINUTE · ARC SECOND
KEEP THE DIMENSIONS STRAIGHT
A8 SECOND = elapsed time.
A8 ARC SECOND = angular displacement.

Matching graduation counts do not make time and angle the same quantity. They make translation across Earth's one-day / one-turn relationship structurally simple.

1 · START WITH THE CLOCK

One A8 civil day is divided into 32 A8 hours. Each hour contains 64 A8 minutes. Each minute contains 64 A8 seconds.

32 × 64 × 64
= 131,072 A8 TIME STATES
= 2^17

2 · NOW TAKE THE SAME EARTH ROTATION AS ANGLE

One complete turn contains 512 A8 angle units. Each A8 angle contains 16 A8 arc minutes. Each A8 arc minute contains 16 A8 arc seconds.

512 × 16 × 16
= 131,072 A8 ANGULAR STATES
= 2^17

The A8 arc second is therefore the terminal graduation of the general A8 angular ruler.

3 · SAME COUNT · DIFFERENT PHYSICAL RULERS

FULL EARTH DAY
= 131,072 TIME STATES

FULL TURN
= 131,072 ANGULAR STATES

One physical recurrence is being described from two viewpoints: elapsed time and angular rotation.

4 · HOUR-SECTOR SYMMETRY

512 ÷ 32
= 16 A8 ANGLE UNITS PER HOUR-SECTOR

One A8 hour contains 4,096 A8 time seconds. Sixteen A8 angle units contain 4,096 A8 arc seconds.

1 A8 HOUR
= 4,096 A8 TIME SECONDS

EARTH ROTATION DURING THAT HOUR
= 4,096 A8 ARC SECONDS

5 · MINUTE SYMMETRY

16 A8 ANGLES ÷ 64 A8 MINUTES
= 1/4 A8 ANGLE PER A8 MINUTE

One quarter A8 angle equals 4 A8 arc minutes. Four A8 arc minutes equal 64 A8 arc seconds.

1 A8 MINUTE
= 64 A8 TIME SECONDS

EARTH ROTATION DURING THAT MINUTE
= 64 A8 ARC SECONDS

9 · A8/CEL · CELESTIAL PRECISION FAMILY

For this celestial instrument, A8/CEL uses a selected base precision rung four binary steps finer than the general angular ruler.

A8/CEL BASE
GENERAL ANGLE +4 RUNGS
= 2^21 STATES / FULL TURN
= 2,097,152

One ordinary A8 arc second therefore spans 16 A8/CEL base states.

1 A8 ARC SECOND
= 16 A8/CEL BASE STATES

Finer or coarser celestial work remains A8/CEL. Only the selected precision rung changes.

10 · WHY 31,306 IS NOT 31,306 ARC SECONDS

Our example arc contains:

1,956.628908288 A8 ARC SECONDS

At the A8/CEL base precision rung:

1,956.628908288 × 16
= 31,306.062532608
A8/CEL FINE ANGULAR STATES

Same physical arc. Finer ruler. The 31,306 value must never be labeled A8 arc seconds.

11 · A8/NAV IS A DIFFERENT PHYSICAL DOMAIN

A8/NAV is reserved for the Earth-anchored distance ruler used in navigation. It is not the name of this angular ruler.

Navigation therefore uses two different physical domains: A8 angle for direction and angular observation, and A8/NAV for Earth-derived distance.

DIRECTION / CELESTIAL POSITION → A8 ANGLE
EARTH NAVIGATION DISTANCE → A8/NAV

A8/NAV is exactly the A8/41 length rung. It remains physically distinct from A8 ANGLE: angle tells which way; NAV tells how far.
