What this page is for

After a common Δ / oscillator change, all three primary moons correctly enter RECALIBRATING together because the old pulse scale became stale at one instant. EARLY recovery remains independent; FULL qualification now uses an equal-duration window: Io 8 · Europa 4 · Ganymede 2 WEST→WEST spans.

The underlying dot coordinate still uses the exact v0.6.20 mapping (x+1)×50% with no left-position smoothing. For visual context only, each moon now runs inside a Jupiter-centered orbital-distance span scaled relative to Callisto: Io 0.224 · Europa 0.356 · Ganymede 0.569 · Callisto 1.000. These display spans never feed recurrence, pulse timing, calibration or recovery. Front/back state continues to use the original simulator geometry.
