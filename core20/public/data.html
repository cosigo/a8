COORDINATE CHECK · OPTIONAL FOLLOW-UP

Internal comparison found 385 moon-pair records with unique absolute positions at exactly matching catalogue dates. The remaining 286 pair records lacked both matching positions. Using first-minus-second coordinates, with differential RA projected by cos(mean declination), 384 matched records agree within approximately 0.413 arcsecond in each coordinate.

We observed a coordinate difference between the two tables for Europa / Callisto at catalogue date 2018/05/05.90303. No catalogue correction or Core20 change is being implemented from this observation at this time. The preserved source files and published analysis are available for anyone who wishes to investigate further.

RELEVANCE TO CORE20
Callisto lies outside the Io–Europa–Ganymede Laplace resonance underlying Core20's three-channel Jovian recurrence recovery. This Europa / Callisto catalogue comparison is supplementary evidence and is not an input to the primary recovery contract. The coordinate observation is therefore retained as an optional investigation opportunity; no Core20 change is being implemented from it at this time.
