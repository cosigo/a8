Whole-turn landmarks

The shared 45/64 scale

This relationship emerged independently from the selected A8 circle and A8 day subdivisions:

ANGLE
1 A8 angle unit
= 45/64 legacy degree
TIME
1 A8 minute
= 45/64 legacy minute
A8 HOUR
1 A8 hour

Interpretation: this is an architectural consequence of 512 angle units/turn and 32×64 minutes/day. It is worth documenting, but it is not evidence that Nature itself uses our numeral system.

Wallflower examples

Some conventional angles translate cleanly because the two rulers share factors. Others become deliberately awkward. We preserve both; no cherry-picking.

π survives the ruler change

π is not defined by degrees. It is the dimensionless ratio of circumference to diameter:

π = C / D

Changing the angular ruler from a 360-part turn to a 512-part turn changes neither the circle nor this ratio.

DECIMAL SPELLING
π ≈ 3.141592653589793…
Same constant written in base 10.
OCTAL SPELLING
π ≈ 3.11037552421026430215…₈
Same constant written in base 8.

A8 does not create a new π. The geometry stays fixed; only the angular ruler and numeral notation change.

Radius proofs on the 512-unit A8 circle

Let θ be an A8 angular amount on a full turn of 1000₈ = 512 A8 units.

GENERAL ARC LENGTH
s = (θ / 512) · 2πr
SOLVE FOR RADIUS
r = (512·s)/(2πθ) = (256·s)/(πθ)
FULL TURN · 1000₈ = 512
C = 2πr
r = C / (2π)
HALF TURN · 400₈ = 256
s = πr
r = s / π
QUARTER TURN · 200₈ = 128
s = πr / 2
r = 2s / π

Circle geometry does not change

CIRCUMFERENCE
C = 2πr
DIAMETER
D = 2r
AREA
A = πr²

A8 changes angular labels, not Euclidean circle geometry, trigonometry, or π.

Observatory rule

When a future astrometry adapter encounters a standard angular quantity, it will keep the original source value intact, cross this translation wall with the exact 64/45 scale, and retain enough fractional octal precision for the observation.
