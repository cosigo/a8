7. Clock Representation

Shared outer phase ruler

Full day phase: Decimal view = 0 → 512 Octal view = 000₈ → 1000₈ 32 A8 hours per day 512 / 32 = 16 decimal phase units per hour 16 decimal = 20₈ phase units per hour

Clock fields follow the same mode

Decimal mode: HH = 00…31 MM = 00…63 SS = 00…63 Octal mode: HH = 00…37₈ MM = 00…77₈ SS = 00…77₈

The outer day phase and the HH:MM:SS decomposition describe the same 32×64×64 = 2¹⁷ daily states.

9. City & Route Atlas
