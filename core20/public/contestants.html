Okay… what’s all this?

What’s Jupiter doing here?

A8 uses observable recurring motion in Jupiter’s moon system as part of its natural timing reference. New to A8? Start with the public quick reference for the clock, number system, angle, tone and Jovian relationship in one place. Open the A8 quick reference →

Why these moons?

Io, Europa and Ganymede expose the recoverable 1:2:4 relationship. Callisto is shown as a useful non-resonant comparison. This is the deeper view of the actual Jovian motion relationship. See the Jovian system →

What’s that strange date?

Eight compass months, planetary weeks and elemental days. The identity above comes from the live server-owned A8 calendar. The Calendar explains why the direction, planet and element shown above change with the native A8 day. Explain today’s A8 date →

What makes the music A8?

The Composer writes note durations in native A8 time. During playback, those musical durations use the same A8 time ruler represented by the Core20 clock. The browser remains the final speaker adapter; it does not define the musical timing. See the A8 clock →
