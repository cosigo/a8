Placard for a future volunteer

1. Run one monotonic free-running counter.
2. Capture its value with each CCD frame.
3. Measure Jupiter center X in pixels.
4. Measure Io / Europa / Ganymede center X in the same frame.
5. Keep originals. Do not pre-convert pixels to degrees for A8.
6. Send CSV:
   frameId,rawPulse,moon,jupiterX,moonX,visible,uncertaintyX

The session does not need to start at WEST. It only needs enough observations around repeated extrema. For full 8:4:2 qualification, long coverage is needed; shorter data can still test early recovery.
