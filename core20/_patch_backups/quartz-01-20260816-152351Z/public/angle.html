Wallflower examples

Some conventional angles translate cleanly because the two rulers share factors. Others become deliberately awkward. We preserve both; no cherry-picking.

π survives the ruler change

π is not defined by degrees. It is the dimensionless ratio of circumference to diameter:

π = C / D

Changing the angular ruler from a 360-part turn to a 512-part turn changes neither the circle nor this ratio.

DECIMAL SPELLING
π ≈ 3.141592653589793…
Same constant written in base 10.
OCTAL SPELLING
π ≈ 3.11037552421026430215…₈
Same constant written in base 8.

A8 does not create a new π. The geometry stays fixed; only the angular ruler and numeral notation change.

Radius proofs on the 512-unit A8 circle

Let θ be an A8 angular amount on a full turn of 1000₈ = 512 A8 units.

GENERAL ARC LENGTH
s = (θ / 512) · 2πr
SOLVE FOR RADIUS
r = (512·s)/(2πθ) = (256·s)/(πθ)
FULL TURN · 1000₈ = 512
C = 2πr
r = C / (2π)
HALF TURN · 400₈ = 256
s = πr
r = s / π
QUARTER TURN · 200₈ = 128
s = πr / 2
r = 2s / π

Circle geometry does not change

C = 2πr

D = 2r
AREA

A8 changes angular labels, not Euclidean circle geometry, trigonometry, or π.
